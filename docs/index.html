Raspberry Pi Greenhouse

A Raspberry Pi 3 that looks after a small herb greenhouse: it runs the grow light and the fan, waters the plants on a schedule, takes a photo every day, and shows everything on its own web page.

View the code on GitHub

What it does

Grow light

On from 06:00 to 20:00, so herbs get a long day even in autumn and winter.

Fan

Cools when it gets hot, and runs a few minutes every hour to keep the air moving.

Watering

A small pump runs for a set time each morning. A time limit in the code stops it from ever running too long.

Camera

One photo a day, so you can follow the plants' growth over weeks.

How it is built

Only one program, greenhouse.py, ever touches the hardware. The web page never switches anything itself: it leaves a request in a small file, and greenhouse.py carries it out within its own safety limits. That keeps the safety rules in one place and means the web page needs no access to the pins at all.

  • Python 3, running as two systemd services that start at boot and restart after a crash.
  • The web page is built with Flask and served by Waitress, with login, lock-out after wrong passwords and protection against forged requests.
  • Remote access goes through a private ZeroTier network, so the page is never open to the internet.

The repository also contains LEARN.md, a beginner-friendly walk through every file and why it is built the way it is.
